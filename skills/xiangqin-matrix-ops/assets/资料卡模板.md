# 单身资料卡模板（线下活动 / 缘分墙用）

## 使用说明
- A4 卡套竖版，半台匿名，**不印手机号、不印真名**
- 男女用不同底色卡片区分
- 上墙前让本人确认信息

## 卡片正面

```
编号：______        性别：□男 □女

昵称：____________  年龄：______  身高：______

学历：____________  职业：____________

定居郑州：□是 □否   所在区域：____________

爱好：____________________________________

期待的 TA：________________________________
__________________________________________

一句话介绍自己：____________________________
__________________________________________

（编号由工作人员填写，联系方式不写在此卡）
```

## 卡片背面（可选）

```
本周最想解决的问题：
□ 扩大圈子  □ 认识靠谱的人  □ 找长期关系  □ 先交朋友

给红娘的备注（不公开）：
__________________________________________
```

| 学历 | 选填 | |
