# 矩阵分工、账号定位与转化路径

## 一、主号：做 IP，圈精准人群

### 定位逻辑
结合本人真实背景立专业人设（广电、留学、街拍摄影等），让别人相信“你是真能帮人对接的人”，而不是一个卖广告的号。

### 主页必须完善
- 头像：真实感、专业感
- 简介：身份 + 能提供什么 + 服务范围（郑州本地）
- 置顶：最能体现价值和真实性的 1-2 条
- 联系方式：只放主页资料区

### 内容原则
1. 输出“有用”的内容：相亲避坑、择偶分析、真实案例复盘、郑州本地资源。
2. **不做单一相亲内容**——纯相亲内容吸引来的是低质量泛流量。
3. 用**职业、收入、地域标签**圈定高净值目标人群：例如“郑州东区国企/体制内/年收入 20w+”。

### 差异化方向（避开泛赛道内卷）
- **人群细分**：校园单身 / 职场单身 / 30+ 大龄
- **场景细分**：郑州网红地点系列街采、写字楼下班实拍
- **身份标识**：电视台工牌、节目话筒标、台标出镜

## 二、水号：承担引流，做好风险隔离

### 任务
- 主职是引流，把人导到主号或私域
- 不追求人设连续性，可以换风格、换素材
- 内容可以更泛、更轻、更快产出

### 禁做
1. 不与主号互关、互赞、互收藏同类内容
2. 不搬运主号已经发过的素材
3. 不在同一网络、同一时间段批量操作
4. 不批量评论、批量私信（每日 2-3 条上限）

## 三、矩阵分工表（照此填写每个号）

| 项 | 主号 | 水号（可多个） |
| --- | --- | --- |
| 目标 | 立人设、圈精准人群、承接转化 | 引流、扩大曝光 |
| 人设 | 必须稳定连续 | 不强求 |
| 内容 | 有用 + 真实案例 + 本地资源 | 泛相亲话题、热点、轻内容 |
| 发布频率 | 稳定，宁少勿滥 | 可高频 |
| 评论区 | 精回复，2-3 条/天 | 少评论，避免被判截流 |
| 联系方式 | 主页资料区 | 主页资料区 |
| 与其它号关系 | 不互关不互赞 | 不互关不互赞 |

## 四、转化路径（核心链路）

```
内容曝光 → 用户进主页 → 关注 / 私信 → 加甲方微信 → 线下活动 / 一对一服务
```

每一步的落地要求：

| 环节 | 要求 |
| --- | --- |
| 曝光 | 内容有人设、有本地标签，标题和前三秒抓郑州本地用户 |
| 进主页 | 主页信息完整，一眼知道你是谁、能提供什么 |
| 关注/私信 | 内容里给“下一步动作”的理由（活动报名、免费看资料） |
| 加微信 | 联系方式放主页资料区，引导用户自己看主页；**不在私信、评论区批量发号** |
| 线下/服务 | 承接要快，明确响应时效，别让线索凉掉 |

### 禁做（合规红线）
1. 禁止群内发跳转码（会被封群、封号）
2. 禁止批量私信回复联系方式
3. 禁止虚假承诺“包脱单”
4. 禁止未经同意使用嘉宾真实姓名、照片、手机号

## 五、数据追踪口径

不拿播放量当唯一标准，分三类看：

| 类型 | 指标 | 说明 |
| --- | --- | --- |
| 传播 | 播放、曝光 | 判断内容能不能推出去 |
| 互动 | 点赞、评论、转发、收藏 | 判断内容能不能打动人 |
| 转化 | 私信数、加微数、报名数 | 判断能不能带来真实用户 |

**核心目标**：拿到郑州本地有真实社交需求的用户，而不是单纯做播放量。

## 六、线下活动配合（物料与话术）

配合线下相亲市集/专场时：
- 现场物料：签到表、资料卡、网格墙、手举牌、提示牌（隐私/禁止偷拍）
- 拍摄：嘉宾出镜必须征得同意，不拍的可以打码
- 现场引导：签到 → 填资料卡上墙 → 扫码进群 → 红娘协助破冰
- 活动后：把到场用户沉淀到私域，48 小时内跟进一次
