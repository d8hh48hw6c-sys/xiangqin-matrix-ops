# 每日竞品情报与河南热点日报

每天早上 8:30 自动产出，也可随时手动触发。是团队选题会的输入，不是自嗨报表。

## 一、触发

- 定时任务：`30 8 * * *`（每天 8:30，Asia/Shanghai，云电脑环境），任务名「相亲赛道日报」
- 用户说“出今天的日报 / 爆款榜 / 河南热点 / 今天能拍什么”时手动跑

## 二、交付两件东西

1. **飞书文档**：结构化全量数据，进共享文件夹，组织内可编辑
2. **转发稿**：一段可直接复制到工作群的完整文案（600 字左右），带链接

两件都要，只给文档不给转发稿等于没交付。

## 三、数据采集

### 1. 抖音作品数据
用 `video_search` 依次搜：`相亲`、`河南相亲`、`彩礼`、`征婚 脱单`、`相亲角`、`红娘`。
每条必须保存：标题、账号类型、点赞、评论、发布时间、**作品直链**。

> 结果按相关度而非时间排序，发布时间可能滞后。文档中如实记录，不许把旧视频写成“今日”。

### 2. 双口径分层
- 评论率 = 评论数 ÷ 点赞数（自算指标，非平台官方）
- **低粉爆款**：点赞 < 5000 且 评论率 > 50%
- **大号爆款**：点赞 > 10000
- 低粉榜按评论率降序

粉丝数在免费通道拿不到，低粉爆款为**代理推断**，文档必须声明。

### 3. 河南方向热点
用 `general_search` 搜：`河南 彩礼`、`河南 相亲`、`郑州 婚介`、`河南 移风易俗`、`河南 骗婚 彩礼`。
侧重郑州、濮阳等本地事件与政策。每条必须存**原文 URL + 发布日期 + 媒体名**。

### 4. 抖音热点榜
抓 `https://tophub.today/n/K7GdaMgdQy`，只筛婚恋、相亲、脱单相关条目，记热度值。

### 5. 不采集
小红书（已明确放弃）。不做无来源的数据填充。

## 四、链接硬要求（最容易出错的地方）

- 作品直链形如 `https://www.iesdouyin.com/share/video/<id>`，每条样本单独保存
- 拿不到直链的样本**不得进入榜单表格**；确需保留时链接列写“—”
- 河南新闻来源列必须是可点开的原文链接，不许只写“某媒体 11 月 12 日”
- 转发稿里低粉前三、河南新闻同样要带链接
- 禁止编造、拼凑、猜测 URL

## 五、文档结构（用 lark-doc 创建）

```bash
lark-cli docs +create --doc-format xml --as user \
  --parent-token AHoFf4GInl3q3ydzajPcswAGn1L \
  --content "@草稿.xml"
```

`--parent-token` 必须带，否则文档不进共享文件夹。

文档结构：

1. **callout 摘要**：今日低粉爆款要点、河南主线、今日可拍选题、数据底色
2. **h1 一、抖音低粉爆款榜**：表格 7 列（内容/类型/点赞/评论/评论率/发布/链接），按评论率降序；链接列 `<a href="直链">看视频</a>`，无链接写“—”；表下写三个共性结构
3. **h1 二、大号爆款参照**：同样 7 列；附“小号该抄什么”的对照结论
4. **h1 三、河南新闻热点**：表格（地区/事件/来源与时间），来源做成 `<a href="原文URL">媒体名</a>` 并写发布日期；表下写主线判断
5. **h1 四、今日可开拍的五个选题**：每条带前三秒话术
6. **h1 五、口径与能力边界**：评论率公式、低粉代理口径、时间窗口、未覆盖项
7. **h1 参考来源**：编号 `ol`，带 `a href`

创建后立即开权限：

```bash
lark-cli drive permission.public patch --token <新文档token> --type docx \
  --data '{"link_share_entity":"tenant_editable","external_access":false}' \
  --as user --yes
```

## 六、转发稿写法（这是用户真正会转出去的东西）

不是内部摘要，是能直接粘到群里的工作消息。要求：

1. 开头直接给结论：今日最值得跟的一条主线 + 最值得抄的一个结构
2. 低粉爆款前三，各一行：内容 / 点赞 / 评论率 / 可抄的点 + 直链
3. 河南新闻 2-3 条，带原文链接 + 一句“这能怎么用”
4. 今日选题 5 条，各带开头三秒话术，简短
5. 明确写“数据截止 X 月 X 日”
6. 结尾附共享文件夹 + 当日文档链接
7. 600 字左右，语气像发给同事的消息，不要公文腔
8. 不出现“我已为您”“根据您的需求”这类助手口吻

## 七、口径（写进文档，不许省）

- 评论率自算，非平台官方指标
- 低粉爆款为代理推断，免费通道不返回粉丝数
- 时间窗口写实际截止日，不称“过去 24 小时”，不用“7 天”
- 抖音数据只覆盖能搜到的公开样本，不代表全站
- 平台侧处罚规则、审核机制以后台通知为准

## 八、常见失败

| 现象 | 处理 |
| --- | --- |
| 搜不到直链 | 该样本不进榜；在文档“未覆盖项”里说明 |
| 数据日期跨度过大 | 如实标日期，摘要里提示“样本偏旧，仅作结构参考” |
| 文档创建失败 | 先检查 `--parent-token` 和身份 `--as user`，不要重试多次 |
| 热点榜抓不到 | 跳过热榜，其余照常，文档里注明该项缺失 |
| 数据量不足 | 宁可少两条，不许凑数、不许编 |
