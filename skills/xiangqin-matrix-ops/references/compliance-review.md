# 合规与风险审查

用户要发内容、写文案、答私信、线下活动物料，或问“这条能不能发”“有没有风险”时读本文件。
本文件是**独立可调用的审查能力**：即使用户只丢来一段现成文案，也按这里过一遍。

## 一、结论只分三级，先说结论

| 级别 | 含义 | 必须给的后续 |
| --- | --- | --- |
| 🟢 绿灯 | 可直接发 | 无需改 |
| 🟡 黄灯 | 改完再发 | 逐条列出：原文位置 → 问题 → 依据 → 改法，并直接给改好的版本 |
| 🔴 红灯 | 不能发 | 说明触犯的是哪一层、为什么不能改、替代方案是什么 |

不下“大概率没问题”“应该可以”这类模糊判断。判断不了的信息，明确写“需账号后台/甲方确认”。

## 二、六层审查（逐层过，任一层命中就记录）

### 第 1 层：平台规则
- 引导私下交易、批量私信发号、评论区留联系方式 → 限流或封号
- 标题党、诱导互动（“点赞过千就揭秘”）→ 降权
- 内容与他号高度同质 → 不进推荐池（无提示）
- 搬运、二次剪辑他人素材 → 侵权 + 低质

### 第 2 层：法律硬线
- **广告法**：禁“最”“第一”“唯一”“顶级”“保证”等绝对化用语；婚介属服务类，不得承诺效果
- **虚假宣传**：不编造成功案例、不虚构“已脱单 XX 对”
- **个人信息保护**：嘉宾姓名、电话、微信、照片、工作单位，未获单独同意不得公开
- **肖像权**：出镜必须口头或书面同意，未同意打码
- **婚介资质**：收费类服务需具备相应经营资质，涉及收费务必提示用户核实主体

### 第 3 层：相亲赛道特有风险
1. **婚托/骗婚**：不暗示“我们安排的人都是真的”，不对个案真实性背书
2. **彩礼话题**：可讨论现象，禁煽动、禁拿具体家庭举例、禁站队骂某一方
3. **性别对立**：禁止“XX 女都物质”“XX 男都不行”这类群体判断
4. **地域与职业歧视**：不贬损任何地区、职业、学历、婚史群体
5. **未成年人**：不涉及在校生婚恋撮合
6. **婚史、生育、身体条件**：属于敏感个人信息，公开前必须本人同意
7. **“包脱单”承诺**：一律禁止，改为“提高匹配效率”“扩大接触面”

### 第 4 层：本地舆情
- 河南/郑州相关政策（移风易俗、彩礼治理）只做中性转述，不做政策评价
- 本地个案、纠纷、案件不点名、不带可识别细节
- 涉及政府部门、媒体单位时，不代其表态

### 第 5 层：内容质量
- 爹味、说教、俯视句式
- 通篇无信息量，只有情绪
- 与他号素材/文案重复

### 第 6 层：数据可信
- 文中每个数字能否说清来源；说不清就删或改成“我们接触到的”
- 案例是否经本人同意、是否可脱敏

## 三、输出格式（固定这样给）

```
【合规结论】🟡 黄灯，改 2 处后可发

| 位置 | 问题 | 依据 | 改法 |
| --- | --- | --- | --- |
| 标题 | “郑州最靠谱的相亲局” | 广告法绝对化用语 | 改为“郑州本地相亲小局” |
| 第 3 句 | 放了嘉宾手机号 | 个人信息保护 | 删号，改“主页看详情” |

【改后版本】
（完整可发布内容）
```

绿灯也要用这个格式，表格留空写“无”。

## 四、必须停下来交回用户确认的情况

1. 涉及具体真人姓名、单位、职务、联系方式
2. 涉及具体案件、纠纷、投诉、赔偿
3. 涉及收费、合同、分成、代理关系
4. 涉及政策解读或对政府/单位的评价
5. 平台处罚力度、申诉结果等平台侧非公开规则 → 写“以后台实际通知为准”，不编造

## 五、和内容输出的关系（硬性要求）

凡是本 Skill 产出内容，**合规审查不许省略、不许后置**：
- 先审后写：选题阶段就判断这个话题能不能碰
- 写完再审：成品交付包里合规结论排在最前
- 审查不通过就不交付成品，只交付“问题 + 替代选题”
