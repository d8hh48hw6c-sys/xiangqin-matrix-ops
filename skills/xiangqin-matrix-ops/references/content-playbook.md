# 内容创作手册：选题、标题、开头、图文、评论区

## 一、选题方法

### 1. 用户视角优先
从用户的痛点、痒点切入，不是从“我们想宣传什么”切入。

**痛点示例（相亲赛道）**：
- 被家里催婚、催到不敢回家
- 条件不差但一直单着，怀疑自己有问题
- 相亲遇到的都是奇葩/托
- 社恐，不知道怎么开口
- 在郑州打拼，圈子小、没机会认识人

**痒点示例**：
- 想找个情绪稳定的搭子
- 想知道郑州本地还有多少优质单身
- 想看看别人怎么脱单的

### 2. 三个维度拓展选题
- **地域**：郑州各区、东区/金水/高新、地标（玉米楼、二七塔、金融岛）
- **职业**：体制内、教师、医护、国企、互联网、创业
- **场景**：通勤、租房、周末、相亲现场、家长会、同学聚会

### 3. 借 AI 工具提关键词
做法：把一条热门相亲内容喂给 AI，让它提取“人群标签 + 情绪关键词 + 场景词”，再用这些词组合成新选题。不要直接抄标题。

## 二、标题公式

组合结构：**数字 + 反问 + 矛盾点**，至少占两样。

| 公式 | 示例 |
| --- | --- |
| 数字 + 身份 | “郑州 30 岁体制内，相亲 17 次全黄了” |
| 反问 + 痛点 | “郑州找对象真的这么难吗？” |
| 矛盾点 | “条件越好的郑州姑娘，越难脱单？” |
| 数字 + 反转 | “相亲 3 年，我最后嫁给了介绍人” |
| 地域 + 冲突 | “在郑州，月薪 8000 的男生还敢不敢谈恋爱” |

**进阶技巧**：标题可以故意留一个小错误（错别字、数字小矛盾），利用用户纠错心理拉评论——但只用在轻松内容，严肃内容不要用，避免显得不专业。

## 三、前三秒开头（决定完播）

三选一，写完再写主体：

1. **反差式**：“我，一个在电视台上班的 90 后，居然要去相亲了。”
2. **冲突式**：“我妈说再找不到对象就别回家了。”
3. **提问式**：“郑州的单身到底都在哪儿？”

禁止开头：
- “大家好，我是 xxx”（自我介绍式，直接划走）
- 大段背景铺垫
- 说教式开场

## 四、图文（plog）规范

1. **头图必须突出身份权威性**：工牌、节目话筒标、台标、工作场景，让用户一眼知道“这是真做相亲的人”。
2. **头图涵盖核心信息**：地点、人群、活动/诉求，一张图说清楚。
3. **避免同质化**：不要用全网通用的相亲配图、模板字；同一套素材不要在多号复用。
4. 正文短句为主，口语化，别写论文。

## 五、去爹味

判断标准：
- 有没有“你应该”“你必须”“现在年轻人就是”这类俯视句式 → 有就删。
- 有没有把用户当学生教育 → 改成“我遇到一个事，你怎么看”。
- 语气是否像朋友聊天 → 不是就像在发通稿。

用户上网是来放松的，不是来上课的。

## 六、评论区运营

### 1. 用开放式提问
- ❌ 封闭式：“你是不是也单身？”（只能回是/否）
- ✅ 开放式：“你在郑州相亲遇到过最离谱的事是什么？”

### 2. 数量控制（硬红线）
- 单账号每日评论 + 私信回复合计 **2-3 条**
- 禁止批量评论、批量私信、批量点赞
- 违反会被判定为截流白号，影响整个账号

### 3. 评论回复结构
1. 先接住情绪（共情一句）
2. 再给一个具体信息或问题
3. 不主动留联系方式，引导看主页

示例：
> 用户：“郑州相亲太难了”
> 回复：“确实，郑州这圈子太小了。你是哪个区的？我们这周有个局，主页有详情。”

## 七、内容自检清单（发布前逐条过）

- [ ] 这条内容对用户“有用”或“有趣”吗？
- [ ] 是按用户视角写的，还是自我表达？
- [ ] 前三秒是反差/冲突/提问之一吗？
- [ ] 标题有数字、反问或矛盾点吗？
- [ ] 头图能一眼看出身份和核心信息吗？
- [ ] 有没有爹味句式？
- [ ] 和其他号的素材、文案重复吗？
- [ ] 里面有没有批量留联系方式/跳转码？
