# 相亲矩阵运营 Skill

相亲交友类抖音账号矩阵的运营执行标准，把一次团队复盘会形成的共识，落成可执行、可复用的判断流程和产出规范。

适用于郑州本地相亲/脱单赛道的账号运营者、婚介机构的内容负责人，以及需要给团队做标准化交付的运营岗。

## 安装

```bash
npx -y skills add d8hh48hw6c-sys/xiangqin-matrix-ops -g --all
```

装好后正常提需求即可触发，也可以点名 `$xiangqin-matrix-ops`。

## 它能做什么

| 能力 | 触发说法 | 产出 |
| --- | --- | --- |
| 养号与账号隔离 | 开新号、养多久、怎么隔离 | 7 天养号流程、账号状态标签、隔离清单 |
| 限流与违规诊断 | 没流量、被限流、收到处罚 | 6 档排查表 + 处置顺序（静置/申诉/回养号） |
| 选题与标题 | 给点选题、起标题 | 5-8 条带痛点标注的选题或标题备选 |
| 成品文案 | 写条文案、出个脚本 | 标题 + 前三秒 + 口播稿 + 封面 + 话题 6 件套 |
| 合规审查 | 这条能不能发、有没有风险 | 绿/黄/红三级结论 + 问题表 + 改后版本 |
| 竞品日报 | 今天的爆款榜、河南热点 | 结构化文档 + 可直接转发的群消息，均带原始链接 |
| 对标与定位 | 同行怎么做的、我们差在哪 | 五类模式拆解、郑州本地实测、四条改法 |
| 矩阵分工 | 主号水号怎么排 | 主号/水号的人设、任务、边界、禁做动作 |

## 最短示例

> 用 $xiangqin-matrix-ops 帮我写一条关于“郑州男生择偶优势”的口播视频，30 秒，主号发。

会返回：

1. 合规结论（绿/黄/红）排在最前，黄灯直接给改后版本
2. 3-5 个标题备选，标注各自打哪个痛点
3. 前三秒 + 按画面分行的口播稿
4. 封面画面与大字、话题标签
5. 合规细节说明

## 两条第一原则

- 内容要么有用，要么有趣，过不了就重写
- 创作视角永远是用户视角，不是自我表达

## 边界与合规

- 平台处罚力度、申诉结果等平台侧非公开规则，Skill 一律要求写明“以后台通知为准”，不编造
- 涉及真人姓名、单位、联系方式、具体案件、收费条款的内容，交回用户确认，不自动生成
- 彩礼等本地政策话题只做中性转述，不做评价
- 所有数据必须可溯源；拿不到链接的样本不进榜单
- 评论率等自算指标会明确标注非平台官方口径

## 依赖

- 生成每日日报需要 `lark-cli`（写入飞书文档并设置权限）；不装也能用其余能力，只是日报改为对话内输出
- 需要联网搜索与抖音作品搜索能力；两者缺失时日报会说明未覆盖项，不凑数
